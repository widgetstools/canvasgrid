SSRM · STOMP DataProvider sample

Hub-backed rowModel: serverSide blotter. Broker: ws://localhost:8082 (npm run dev:stomp → ssrm-grid stomp-view-server).

  1. Start the STOMP broker (npm run dev:stomp in another terminal).
  2. Open Settings (Customize drawer) → Data → Data provider.
  3. Select STOMP SSRM Positions → Apply (saved for reload; live ticks flash when Change flash is on).
