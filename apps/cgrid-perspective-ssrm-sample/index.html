VelocityGridExt · Perspective SSRM

Ext chrome with Data provider plumbing bound to StompPerspectiveProvider. Broker: ws://localhost:8082 (npm run dev:stomp).

  1. Open Customize → Data → Data provider.
  2. Select Perspective SSRM Positions → Apply.
  3. Edit… opens the shared DataProvider editor (Connection / Fields / Columns / Behaviour / Diagnostics).
  4. Apply binds StompPerspectiveProvider (SSRM) from that catalog entry.
