# ADR-002 — One design system + authoring grammar

## Decision

All Customize / ProviderEditor / ribbon chrome uses `@wellsfargo-starui/vg-new-ui`.

Authoring: Draft → Validate → Apply/Save. Dirty discard on rail switch.

## Consequences

Legacy Lit `customizer` and dual `ckp-*` / `vg-dp-*` kits are not ported.
