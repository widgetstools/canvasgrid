02 — The system

One row grammar, one button ladder, one chip

Every screen in the product is a list of settings. If the row is the same everywhere, the screens stop looking authored by different people.

Row grammar — label left, control right, help under the label

Help text moves under the label, not under the control, so the control column stays a clean vertical edge and long help never pushes the next control down. Sentence case, never uppercase.
