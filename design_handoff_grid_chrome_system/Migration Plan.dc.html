The seam already exists

Someone started this work already. packages/kernel/src/ui/primitives.ts exists to be exactly this shared layer, and its own header comment states the problem in the same terms this review did:

Both the ext cockpit kit (.ckp-*) and the data-provider editor kit (.vg-dp-*) were hand-rolled independently and drifted (e.g. the toggle switch); these generators let each kit keep its own class names, state classes, and layout CSS while sourcing the primitive look from one place, so they can no longer diverge.

It ships three generators — vguiSwitchCss, vguiCapsCss, vguiInputInteractionCss — and the cockpit already consumes all three. The plan is to widen it, not to build something new. Its stated design constraints (no shared class names, plain CSS strings, token-driven) hold for everything below.
